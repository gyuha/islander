# 에셋 명세: buoy (구명 튜브 부표, 장식)

| 항목 | 값 |
|---|---|
| 용도 | 섬 둘레 바다에 떠 있는 장식 3개. 상하로 흔들림(코드) |
| 출력 | `assets/models/buoy/buoy.glb` |
| 생성 스크립트 | `tools/blender/buoy.py` |
| 크기 | 바깥 지름 0.8 m, 튜브 두께 0.2 m (높이 0.2 m) |
| 원점 / 축 | 바닥 중앙(토러스 아래면 y = 0), +Y 위, 수평으로 누운 자세 |
| 삼각형 | ≤ 400 (상한 1,500) |
| 스타일 | 참조 이미지 물 위의 분홍·흰 구명 튜브 |

## 형태

| 오브젝트 | 형태 | 색 |
|---|---|---|
| `Ring` | 토러스(주 세그먼트 24, 부 세그먼트 10), 90°씩 4구간 색 교차 | white_warm `#F9F6E5` / red `#DD5161` 교차 |

## 머티리얼

`M_white_warm`, `M_red`.

## 배치·충돌

충돌 없음. 코드가 y = −0.08에 두고 0.3 m 진폭, 2.5초 주기로 흔든다.

## 검수

삼각형 ≤ 1,500, 바운딩 박스 0.8 × 0.2 × 0.8 m(±10%).
