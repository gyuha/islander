# 에셋 명세: slime (슬라임)

| 항목 | 값 |
|---|---|
| 용도 | 밤에 나타나 플레이어를 쫓는 몬스터. 스쿼시 앤 스트레치를 코드로 |
| 출력 | `assets/models/slime/slime.glb` |
| 생성 스크립트 | `tools/blender/slime.py` |
| 크기 | 폭 0.75 m, 높이 0.60 m, 깊이 0.70 m |
| 원점 / 축 | 바닥 중앙 (0,0,0), +Y 위, 정면 +Z |
| 삼각형 | ≤ 1,200 (상한 3,000) |
| 스타일 | 둥근 젤리 방울(물방울을 눌러 놓은 형태), 아래가 살짝 퍼짐. 무광 클레이, 투명 아님. 귀엽지만 눈썹이 살짝 화난 표정 |

## 오브젝트 계층

```
Slime (Empty, 원점 0,0,0)
└─ Body        피벗 (0, 0, 0)  바닥 중앙 — y 스케일 스쿼시가 바닥에 붙은 채로 되게
   └─ Face     피벗 (0, 0.30, 0.33)
```

| 파츠 | 형태 | 색 |
|---|---|---|
| Body | 바닥 평평한 돔, 위가 둥근 물방울 꼭지(살짝 기울어진 뾰족 끝 없이 둥글게), 바닥 둘레 립 | slime `#9C7BD6`, 윗면 하이라이트 패치(머리 꼭대기 얇은 셸) `#B9A0E6` |
| Face | 눈 2(세로 타원 0.07×0.10, 간격 0.18), 눈 위 짧은 사선 눈썹 2(안쪽이 내려감), 볼 원 2(지름 0.07). 몸 표면에 붙인 얇은 셸 | 눈·눈썹 ink `#2B2233`, 볼 blush `#F2A0B8` |

## 머티리얼

`M_slime`, `M_slime_light`(`#B9A0E6`), `M_ink`, `M_blush`.

## 충돌

glb에 넣지 않는다. 씬에서 구 r 0.35, 중심 y 0.35.

## 검수

삼각형 ≤ 3,000, `Body`·`Face` 존재, Body 피벗이 바닥 중앙, 바운딩 박스 0.75 × 0.60 × 0.70 m(±10%).
