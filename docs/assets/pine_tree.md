# 에셋 명세: pine_tree (소나무)

| 항목 | 값 |
|---|---|
| 용도 | 채집 대상(나무 드롭). 섬 1·2단에 최대 30그루 |
| 출력 | `assets/models/pine_tree/pine_tree.glb` |
| 생성 스크립트 | `tools/blender/pine_tree.py` |
| 크기 | 높이 3.6 m, 최대 지름(맨 아래 단) 2.2 m |
| 원점 / 축 | 바닥 중앙 (0,0,0), +Y 위, 정면 +Z (Blender: +Z 위, 정면 −Y, glTF 내보내기 +Y Up) |
| 삼각형 | ≤ 900 (상한 1,500) |
| 스타일 | `docs/art/style-guide.md` 1·3절. 참조 이미지 왼쪽의 3단 소나무 |

## 형태

참조의 소나무처럼 부풀린 원뿔 3단을 쌓는다. 각 단 아래 가장자리는 둥글게 말린 립이 있고, 단끼리 살짝 겹친다.

| 오브젝트 | 형태 | 크기 | 위치(바닥 기준 y) | 색 |
|---|---|---|---|---|
| `Trunk` | 원기둥, 위가 약간 가늚 | 지름 0.45→0.35, 높이 1.0 | 0 ~ 1.0 | trunk `#8A5A3B` |
| `Tier1` | 부풀린 원뿔 + 아래 립 | 지름 2.2, 높이 1.3 | 0.7 ~ 2.0 | leaf_dark `#2F8F57` |
| `Tier2` | 〃 | 지름 1.7, 높이 1.1 | 1.6 ~ 2.7 | leaf `#3FA463` |
| `Tier3` | 〃, 꼭대기 둥글게 | 지름 1.1, 높이 1.0 | 2.6 ~ 3.6 | leaf `#3FA463` |

- 각 Tier의 아래 면은 leaf_shadow `#285538`로 칠해도 된다(머티리얼 1개 추가 허용).
- 오브젝트를 합쳐도 되지만 이름은 루트 `PineTree` 하나로. 코드에서 파츠를 움직이지 않는다.

## 머티리얼

`M_trunk`, `M_leaf_dark`, `M_leaf`, (선택) `M_leaf_shadow`. Roughness 0.85, Metallic 0.

## 충돌

glb에 충돌 메시를 넣지 않는다. `scenes/world/pine_tree.tscn`에서 `Blocker` 원기둥 r 0.35 h 2.0, `InteractShape` 원기둥 r 0.9 h 2.0으로 정의.

## 검수

삼각형 수 ≤ 1,500, 바운딩 박스 ≈ 2.2 × 3.6 × 2.2 m(±10%), 최저점 y = 0, 스무스 셰이딩.
