# 에셋 명세: rock (바위)

| 항목 | 값 |
|---|---|
| 용도 | 채집 대상(돌 드롭). 최대 20개 |
| 출력 | `assets/models/rock/rock.glb` |
| 생성 스크립트 | `tools/blender/rock.py` |
| 크기 | 1.2 (x) × 0.8 (y) × 1.0 (z) m |
| 원점 / 축 | 바닥 중앙, +Y 위, 정면 +Z |
| 삼각형 | ≤ 400 (상한 1,500) |
| 스타일 | 강 조약돌처럼 둥글고 납작한 덩어리. 날카로운 각 없음 |

## 형태

| 오브젝트 | 형태 | 크기 | 색 |
|---|---|---|---|
| `RockBody` | 큰 둥근 덩어리(세분화 구를 납작하게 + 약한 변형), 바닥 평평 | 1.2 × 0.8 × 1.0 | stone `#9BA7A6` |
| `RockSmall` | 옆에 붙은 작은 덩어리 1개 | 0.45 × 0.35 × 0.4, 본체 +X 앞쪽에 반쯤 묻힘 | stone_light `#C4CDCB` |
| `Moss` | 윗면 일부를 덮은 얇은 이끼 패치(본체 위 0.02 m 띄운 셸) | 윗면의 25% | grass `#5DB85E` |

변형은 저주파(노이즈 스케일 ≥ 0.5 m)만 써서 점토 덩어리처럼 보이게 한다.

## 머티리얼

`M_stone`, `M_stone_light`, `M_grass`.

## 충돌

glb에 넣지 않는다. 씬에서 `Blocker` 원기둥 r 0.6 h 0.8, `InteractShape` 원기둥 r 0.9 h 1.2.

## 검수

삼각형 ≤ 1,500, 바운딩 박스 1.2 × 0.8 × 1.0 m(±10%), 최저점 y = 0.
