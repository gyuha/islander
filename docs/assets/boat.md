# 에셋 명세: boat (나룻배, 장식)

| 항목 | 값 |
|---|---|
| 용도 | 해변 앞 바다에 떠 있는 장식. 상호작용 없음 |
| 출력 | `assets/models/boat/boat.glb` |
| 생성 스크립트 | `tools/blender/boat.py` |
| 크기 | 길이 2.6 m (z), 폭 1.1 m, 높이 0.6 m (선체) |
| 원점 / 축 | 선체 바닥 중앙, +Y 위, **뱃머리 +Z** |
| 삼각형 | ≤ 1,200 (상한 1,500) |
| 스타일 | 참조 이미지 왼쪽 아래의 작은 나무 나룻배: 두툼한 뱃전, 둥근 뱃머리, 노 2개 |

## 형태

| 오브젝트 | 형태 | 색 |
|---|---|---|
| `Hull` | 속이 빈 둥근 선체, 뱃전 두께 0.08, 뱃전 윗면에 굵은 테(베벨 큼). 바깥 판자 줄 2개는 색 띠로만 | 바깥 earth `#C36F46`, 테 earth_dark `#985033`, 안쪽 wood_light `#BE946D` |
| `Seat` | 가로 판 2개(z = ±0.4), 두께 0.06 | wood_dark `#876C46` |
| `Oars` | 노 2개, 선체 안에 비스듬히 걸침(한 개는 뱃전 밖으로 0.4 m 나옴), 자루 지름 0.05, 날 0.4 × 0.15 | wood_light |

## 머티리얼

`M_earth`, `M_earth_dark`, `M_wood_light`, `M_wood_dark`.

## 배치·충돌

코드가 y = −0.15에 두어 물에 잠기게 하고 ±3° 흔들림 Tween을 준다. 충돌은 씬(`scenes/world/boat.tscn`)에서 StaticBody3D(layer 1) 박스 1.0 × 0.6 × 2.4.

## 검수

삼각형 ≤ 1,500, 바운딩 박스 1.1 × 0.6(노 제외) × 2.6 m(±10%), 뱃머리 +Z.
