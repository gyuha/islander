# 에셋 명세: crab (게)

| 항목 | 값 |
|---|---|
| 용도 | 해변 순찰 몬스터. 코드에서 모델을 90° 돌려 옆걸음, 다리·집게를 코드로 움직임 |
| 출력 | `assets/models/crab/crab.glb` |
| 생성 스크립트 | `tools/blender/crab.py` |
| 크기 | 폭(다리 포함) 1.0 m, 높이(눈 끝) 0.50 m, 깊이(집게 포함) 0.75 m |
| 원점 / 축 | 바닥 중앙 (0,0,0), +Y 위, **정면 +Z = 집게 방향** |
| 삼각형 | ≤ 2,500 (상한 3,000) |
| 스타일 | 납작하고 둥근 등딱지, 큰 집게 2개, 짧은 눈자루. 장난감 같은 둥근 다리 |

## 오브젝트 계층과 피벗

```
Crab (Empty, 원점 0,0,0)
├─ Body        피벗 (0, 0.12, 0)        등딱지 바닥 중앙
├─ ClawL       피벗 (+0.28, 0.24, 0.15) 어깨
├─ ClawR       피벗 (-0.28, 0.24, 0.15)
├─ LegsL       피벗 (+0.26, 0.20, 0)    왼쪽 다리 3개 묶음(한 오브젝트)
└─ LegsR       피벗 (-0.26, 0.20, 0)
```

L = 게 기준 왼쪽 = +X.

| 파츠 | 형태 | 크기 | 색 |
|---|---|---|---|
| Body | 납작한 타원체 등딱지(위 볼록, 아래 평평), 앞 가장자리에 눈자루 2개(원기둥 0.04 × 0.12) + 눈(구 지름 0.08, 흰자에 검은 점), 입 작은 선 | 0.60 × 0.28 × 0.45, y 0.12~0.40, 눈 끝 0.50 | crab `#E0573A`, 배 cream `#F2E7BB`, 눈 white_warm `#F9F6E5` + ink `#2B2233` |
| ClawL / ClawR | 굵은 팔 캡슐 + 둥근 집게(위 턱·아래 턱이 V로 벌어진 하나의 메시) 앞쪽·바깥으로 | 집게 0.22 × 0.16 × 0.20, 끝 위치 x ±0.45, z 0.38 | crab, 집게 끝 rust `#8C341F` |
| LegsL / LegsR | 다리 3개(앞·중·뒤, z = +0.12/0/−0.12), 각 다리는 굵은 캡슐 2마디로 바깥·아래로 꺾여 끝이 y = 0, x ±0.5 | 다리 지름 0.05 | crab |

- 다리 끝 3개가 바닥(y = 0)에 닿아 몸을 받친다.

## 머티리얼

`M_crab`, `M_cream`, `M_rust`, `M_white_warm`, `M_ink`.

## 충돌

glb에 넣지 않는다. 씬에서 박스 0.8 × 0.4 × 0.6, 중심 y 0.2.

## 검수

삼각형 ≤ 3,000, 오브젝트 5개 이름 일치, 피벗 ±0.01 m, 바운딩 박스 1.0 × 0.5 × 0.75 m(±10%), 집게가 +Z.
