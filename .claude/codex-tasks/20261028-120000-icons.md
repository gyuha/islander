# Task: produce 6 item icons (clay 3D style, transparent PNG)

Attached style references (use them for palette, lighting, and clay material feel):
- assets/concept/reference.webp (island scene reference; night = teal tones)
- assets/concept/concept_sheet.png

## Global style (all 6 icons must read as one set)
- Soft clay 3D render, toy-like, rounded bulky forms, rounded bevels, no sharp edges.
- 3/4 view from about 30 degrees above.
- Light from upper-left. Matte (non-glossy), no specular highlights beyond a soft sheen.
- NO outline/stroke. NO ground shadow or contact shadow. NO text, NO letters, NO UI frame.
- Large, simple silhouettes that read at small size (object built from 2-4 big chunks).
- Use ONLY these colors (sRGB hex) for the object: trunk #8A5A3B, wood_light #BE946D, wood_dark #876C46, stone #9BA7A6, stone_light #C4CDCB, red #DD5161, leaf #3FA463, leaf_dark #2F8F57, orange #E79C62, cream #F2E7BB.
- Background: a single flat pure chroma-key color #00FF00 (pure green) filling the entire canvas, nothing else in the background, no gradient, no shadow on background. Object must NOT contain pure #00FF00 anywhere.

## Output method
Generate each image with the built-in `image_gen` tool, then save the result to the path given below. Make each object centered in a square canvas with generous padding (object occupies about 80% of the frame).

## Post-processing (Python with Pillow, run with python3 -I, script saved in a scratch directory outside assets)
For each generated image:
1. Load it as RGB.
2. Build alpha: pixels close to #00FF00 become transparent. Use a color-distance threshold (e.g., distance < 90 in RGB → alpha 0; between 90 and 160 → partial alpha for anti-aliasing; only remove green-dominant pixels, i.e. G much greater than R and B). Also make sure the removal only touches background connected to the image border if possible, so green-ish object pixels are not punched out.
3. Crop to the bounding box of alpha > 0.
4. Scale the object so that its longest side is exactly 112 px (LANCZOS), keeping aspect ratio.
5. Paste onto a 128x128 RGBA canvas of (0,0,0,0), centered (offset = (128 - w)//2, (128 - h)//2).
6. Verify: canvas mode RGBA, size 128x128, all four corner pixels have alpha 0, object bounding box lies within 8 px from every edge.
7. Save as PNG to the target path above (create the directory if missing).

## Required final output
Print, for each icon: saved absolute path, size, mode, whether the image has real alpha (count of alpha==0 pixels and alpha==255 pixels), and bounding box of the object. If any icon fails a check, say so explicitly. Retry generation at most once per icon.
