# 에셋 명세: player_human (플레이어 꼬마 탐험가)

| 항목 | 값 |
|---|---|
| 용도 | 플레이어 캐릭터. 리깅 없이 파츠를 코드(Tween)로 움직인다 |
| 출력 | `assets/models/player_human/player_human.glb` |
| 생성 스크립트 | `tools/blender/player_human.py` |
| 크기 | 높이 0.95 m(머리카락 포함), 폭 0.46 m(머리 기준), 깊이 약 0.46 m(얼굴 앞 z +0.21 ~ 배낭 뒤 z −0.245) |
| 원점 / 축 | 루트 원점 = 발 사이 바닥 중앙 (0,0,0), +Y 위, **정면 +Z** (Blender: 정면 −Y) |
| 삼각형 | ≤ 2,800 (상한 3,000) |
| 스타일 | 참조 이미지의 클레이 장난감 스타일. 약 2.5등신의 귀여운 꼬마 탐험가, 성별 중립. 짧고 부스스한 갈색 머리, 둥근 얼굴, 크고 짙은 눈, 발그레한 볼. 크림색 반팔 셔츠, 주황 스카프(플레이어 구분 표식), 갈색 반바지·부츠, 작은 갈색 배낭 |

## 오브젝트 계층과 피벗

각 파츠의 **오브젝트 원점(피벗)을 관절 위치**에 둔다. 코드가 피벗 기준으로 회전한다. 회전·스케일만 적용(Apply Rotation & Scale)하고 위치는 피벗 오프셋으로 남긴다. 이름은 아래와 정확히 일치해야 한다.

```
PlayerHuman (Empty, 원점 0,0,0)
├─ Body          피벗 (0, 0.20, 0)          엉덩이
│  ├─ Head       피벗 (0, 0.52, 0)          목
│  ├─ ArmL       피벗 (+0.18, 0.46, 0)      어깨
│  └─ ArmR       피벗 (-0.18, 0.46, 0)
│     └─ ToolSocket (Empty) 위치 (-0.18, 0.30, 0.03)   손 중심, 도구 부착점
├─ LegL          피벗 (+0.08, 0.20, 0)      고관절
└─ LegR          피벗 (-0.08, 0.20, 0)
```

좌표는 모두 루트 기준 Godot 좌표(m)다. L은 캐릭터 기준 왼쪽(+X), R은 오른쪽(−X) — 정면이 +Z이므로 캐릭터의 왼쪽이 +X다.

## 파츠 형태

아래 y 범위는 루트 기준 절대 높이다. 비례: 머리(y 0.53~0.95, 0.42 m)가 전체 높이의 44% — 스타일 가이드 1절의 40~45% 범위 안.

| 파츠 | 형태 | 크기 (폭×높이×깊이) / 위치 | 색 |
|---|---|---|---|
| Body — 몸통 | 아래가 약간 넓은 둥근 통(달걀형에 가까움). 위 폭 0.30, 아래 폭 0.34. 위쪽(y 0.27~0.52)은 셔츠, 아래쪽(y 0.14~0.27)은 반바지. 반바지 밑단은 폭 0.36으로 살짝 퍼지고 둥근 립 처리 | 0.34 × 0.38 × 0.26, y 0.14~0.52 | 셔츠 cream `#F2E7BB`, 반바지 trunk `#8A5A3B` |
| Body — 스카프 | 목둘레 납작한 토러스(바깥 지름 0.32, 단면 두께 0.06, 중심 y 0.51). 앞(+Z)에 매듭 구(지름 0.07, 중심 (0, 0.49, 0.15)). 매듭 아래로 꼬리 1개: 둥근 납작 박스 0.07 × 0.14 × 0.03, y 0.36~0.49, z 0.15, 캐릭터 왼쪽(+X)으로 15° 기울임 | 위 값 | orange `#E79C62` |
| Body — 배낭 | 등(−Z)에 붙은 둥근 박스, 베벨 크게. 위에 덮개(0.25 × 0.07 × 0.12, 배낭 윗면에 얹힘). 어깨끈 2개: 폭 0.03, 두께 0.015 띠가 배낭 윗면에서 어깨를 넘어 앞면 x ±0.09, y 0.30~0.48까지 내려옴(위쪽은 스카프 밑으로 들어감) | 본체 0.24 × 0.24 × 0.11, 중심 (0, 0.38, −0.19) | trunk |
| Head — 얼굴 | 약간 납작한 구. 귀는 별도 오브젝트로 만들지 않는다. 옆머리가 덮거나, 작은 귀가 보이면 Head 메시에 합친다(EarL/EarR 같은 파츠 이름 금지) | 0.42 × 0.38 × 0.40, 중심 (0, 0.72, 0.01), y 0.53~0.91 | skin `#F2C6A0` |
| Head — 머리카락 | 정수리·뒤통수·옆을 덮는 두툼한 캡(얼굴 구보다 바깥으로 0.02 부풀림). 앞머리는 이마를 덮어 y 0.80까지 내려오고 끝이 3갈래 둥근 덩어리로 갈라짐. 뒤는 y 0.62까지, 옆은 y 0.66까지. 부스스함: 둥근 원뿔 덩어리 6개(길이 0.05~0.07)를 정수리·옆머리에서 위·바깥으로 삐침. 정수리 삐침 1개가 최고점 y 0.95 | 0.46 × 0.40 × 0.44, y 0.55~0.95 | trunk |
| Head — 눈 | 세로 타원 2개, 얼굴 표면에 살짝 돌출(0.01). 각 눈의 위·캐릭터 왼쪽(+X +Y 방향 0.012, 0.018)에 하이라이트 구(지름 0.018) | 0.055 × 0.075, 중심 x ±0.075(간격 0.15), y 0.70 | 눈 ink `#2B2233`, 하이라이트 cream |
| Head — 볼 | 납작한 원판 2개, 얼굴 표면에 붙임 | 지름 0.07, 중심 x ±0.13, y 0.65 | blush `#F2A0B8` |
| Head — 입 | 작은 웃는 호(가는 곡선 캡슐), 얼굴 표면에 붙임 | 폭 0.04, 두께 0.008, 중심 (0, 0.635, 표면) | ink |
| ArmL / ArmR | 짧은 캡슐(피부)이 아래로 늘어짐. 위에 반팔 소매: 아래가 살짝 벌어진 원기둥(지름 0.11, y 0.39~0.48, 윗부분은 몸통에 파묻힘). 끝에 둥근 손(구 지름 0.10, 중심 y 0.30) | 팔 지름 0.085, y 0.25~0.48 (피벗 x에 중심) | 팔·손 skin, 소매 cream |
| LegL / LegR | 짧은 캡슐 다리(위쪽은 반바지 안에 묻힘) + 둥근 부츠. 부츠: 베벨 큰 박스, 바닥 평평, 발끝이 +Z로 0.04 나옴, 윗단에 두께 0.015 둥근 테(폭 0.14) | 다리 지름 0.10, y 0.08~0.20. 부츠 0.13 × 0.10 × 0.17, y 0~0.10, z −0.06~+0.11 | 다리 skin, 부츠 trunk |

- 기본 자세: 똑바로 선 자세(A포즈 아님, 팔은 몸 옆으로 내림), 모든 파츠 회전 0.
- 머리카락·눈·볼·입은 Head에 합치고, 스카프·배낭(덮개·어깨끈 포함)은 Body에 합친다. 소매·손은 각 Arm에, 부츠는 각 Leg에 합친다.
- 폭 0.46 m는 머리(머리카락 포함)가 결정한다. 팔 바깥 끝은 x ±0.225로 머리보다 안쪽이어야 한다.
- 삼각형 배분 권장: Head ≤ 1,200(얼굴 500, 머리카락 550, 얼굴 요소 150), Body ≤ 900(몸통 300, 스카프 250, 배낭·끈 350), Arm 각 ≤ 150, Leg 각 ≤ 200.

## 머티리얼

`M_skin`, `M_trunk`, `M_cream`, `M_orange`, `M_ink`, `M_blush` (6개). Roughness 0.85.

스타일 가이드 3절의 "에셋당 머티리얼 ≤ 6개" 제한 때문에 머리카락·반바지·부츠·배낭의 갈색을 `trunk` 하나로 통일한다. 각 갈색 파츠는 피부(다리·얼굴)나 크림(셔츠)으로 서로 떨어져 있으므로 실루엣 구분에는 지장이 없다. 눈 하이라이트도 흰색을 따로 두지 않고 `cream`을 재사용한다.

## 충돌

glb에 넣지 않는다. 씬에서 캡슐 r 0.3, 높이 0.9, 중심 y 0.45. (모델 최고점 0.95 m는 캡슐 위로 0.05 m 나오며, 머리카락 끝이라 문제없다.)

## 검수

삼각형 ≤ 3,000, 머티리얼 6개, 오브젝트 이름 7개(PlayerHuman, Body, Head, ArmL, ArmR, LegL, LegR) + ToolSocket 존재, 각 피벗과 ToolSocket 위치가 표와 ±0.01 m, 최저점 y = 0, 최고점 y = 0.95 ±0.01, X 방향 전체 폭 0.46 ±0.01, 얼굴이 +Z를 향함, 귀 전용 오브젝트 없음(귀는 Head에 합쳐도 됨), 기본 자세에서 모든 파츠 회전 0.
