## Modeling rules
- Units: 1 Blender unit = 1 m. Godot convention: +Y up, origin at bottom-center, front = +Z.
  - Blender is Z-up. Build in Blender coordinates and let the glTF exporter convert (Blender Z-up → glTF Y-up). Final bounding box in Godot space must be 1.2 (x) × 0.8 (y) × 1.0 (z) m, lowest point y = 0, origin at bottom center.
  - Use the correct mapping so that the Godot-space bbox matches the spec exactly. Verify after export.
- Apply all transforms (scale/rotation) before export.
- Shading: smooth shading + Auto Smooth / Smooth by Angle 40°. No flat shading.
- Bevel rule (style guide 1): where boxy edges exist, bevel with width 10–15% of the shortest dimension of the part, 2–3 segments, Limit Method = Angle 30°, then apply. Rounded organic forms are preferred over hard edges.
- Flat bottom face (ground contact).
- Low-frequency noise deformation only (noise scale >= 0.5 m) so it reads as a clay lump.
