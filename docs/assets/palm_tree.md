# 에셋 명세: palm_tree (야자수)

| 항목 | 값 |
|---|---|
| 용도 | 채집 대상(나무 드롭). 해변 띠에 최대 10그루 |
| 출력 | `assets/models/palm_tree/palm_tree.glb` |
| 생성 스크립트 | `tools/blender/palm_tree.py` |
| 크기 | 높이 4.2 m, 잎 펼친 지름 3.2 m |
| 원점 / 축 | 바닥 중앙 (0,0,0), +Y 위, 정면 +Z |
| 삼각형 | ≤ 1,200 (상한 1,500) |
| 스타일 | 참조 이미지 집 뒤 야자수: 짧고 넓은 잎이 둥글게 늘어짐 |

## 형태

| 오브젝트 | 형태 | 크기 | 색 |
|---|---|---|---|
| `Trunk` | 굽은 원기둥, 마디 6개(마디마다 살짝 볼록한 링) | 지름 0.35→0.25, 높이 3.6, 꼭대기가 +X로 0.5 m 기울어짐 | wood_light `#BE946D`, 링 wood_dark `#876C46` 교차 |
| `Leaves` | 넓은 잎 7장, 두께 0.06 이상(종잇장 금지), 끝이 아래로 처짐, 잎 끝 둥글게 | 잎 길이 1.5, 폭 0.5 | palm_leaf `#6DB33F` |
| `Coconuts` | 구 3개, 잎 밑동 | 지름 0.22 | wood_dark `#876C46` |

- 잎은 한 장 메시를 회전 복제(360/7°)하고 각 장을 ±10° 무작위 처짐(시드 고정).
- 줄기 기울기 때문에 잎 중심이 원점에서 0.5 m 벗어나도 원점은 줄기 밑동 중앙.

## 머티리얼

`M_wood_light`, `M_wood_dark`, `M_palm_leaf`.

## 충돌

glb에 넣지 않는다. 씬에서 `Blocker` r 0.3 h 2.0, `InteractShape` r 0.9 h 2.0.

## 검수

삼각형 ≤ 1,500, 높이 4.2 m(±10%), 최저점 y = 0, 잎이 양면 렌더링 없이도 구멍 없이 보일 것(두께 있음).
