# 에셋 명세: berry_bush (베리 덤불)

| 항목 | 값 |
|---|---|
| 용도 | E로 베리 3개 채집, 60초 뒤 열매 재생. 최대 12개 |
| 출력 | `assets/models/berry_bush/berry_bush.glb` |
| 생성 스크립트 | `tools/blender/berry_bush.py` |
| 크기 | 지름 1.0 m, 높이 0.8 m |
| 원점 / 축 | 바닥 중앙, +Y 위, 정면 +Z |
| 삼각형 | ≤ 800 (상한 1,500) |
| 스타일 | 참조 이미지 집 앞 클로버 덤불처럼 둥근 잎 덩어리가 뭉친 모양 |

## 형태

| 오브젝트 | 형태 | 크기 | 색 |
|---|---|---|---|
| `Leaves` | 겹친 구 5개(가운데 큰 것 1 + 둘레 4), 아래는 평평 | 전체 1.0 × 0.8 × 1.0 | leaf `#3FA463`, 큰 구 윗부분 grass_light `#79C46A` 허용 |
| `Berries` | 작은 구 9개를 잎 표면에 반쯤 박음, **하나의 오브젝트로 합칠 것** | 구 지름 0.14 | red `#DD5161`, 하이라이트 없음 |

`Berries`는 반드시 별도 오브젝트로, 이름을 정확히 `Berries`로 둔다. 코드가 열매를 딴 뒤 이름으로 찾은 `Berries` 노드를 숨기고 재생 시 다시 보여 준다.

## 머티리얼

`M_leaf`, `M_grass_light`, `M_red`.

## 충돌

블로커 없음(통과 가능). 씬에서 `InteractShape` 원기둥 r 0.7 h 1.0.

## 검수

삼각형 ≤ 1,500, `Berries` 오브젝트 존재, 바운딩 박스 1.0 × 0.8 × 1.0 m(±10%).
